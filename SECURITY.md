# Security Policy

## Reporting a vulnerability

Email **security@festie.us** with steps to reproduce. We aim to reply within 48 hours.

If email is not available, open a private security advisory on GitHub (Security tab, "Report a vulnerability").

Do not open a public GitHub issue for a security problem.

Include the affected URL or app version, what you expected, what happened, and any proof of concept. Test only against your own account and data.

## Scope

In scope: the festie.us web app, its API, and the Festie mobile app.

Out of scope: denial-of-service and load testing, spam or social engineering, physical attacks, and third-party services we use (report those to the vendor).

## What happens next

1. We confirm receipt within 48 hours.
2. We triage the report and tell you whether we accept it as a vulnerability.
3. We fix accepted issues by severity and tell you when the fix ships.
4. We credit you in the release notes if you want credit.

We keep an internal incident response procedure. It is not published here.

## Supported versions

We fix security issues in the version deployed at festie.us and in the latest published mobile app release.

## Privacy

For personal-data questions, email **privacy@festie.us**.
