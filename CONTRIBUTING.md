# Contributing

Festie is **proprietary software** (see [LICENSE](LICENSE)). It is not open source and is **not accepting external contributions, forks, or redistribution**.

## Security

If you've found a security vulnerability, please report it privately per [SECURITY.md](SECURITY.md). Do **not** open a public issue for security findings.

## Commits and branches

- Write commit subjects in the imperative mood, without a type prefix: "Fix race condition in token refresh".
- Explain why the change is needed, not what the diff already shows.
- Make one logical change per commit.
- Name branches with a `feat/`, `fix/` or `chore/` prefix and kebab-case words, such as `fix/parcel-query-timeout`.
- Production tracks `main`. Open a pull request against `main`.
